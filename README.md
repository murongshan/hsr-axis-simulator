# 简易排轴模拟器

## 是什么

由 Muse 空间「简易排轴模拟器」转换的部署版项目，仓库名 hsr-axis-simulator，目标形态：开源公开仓 + GitHub Pages。

## 在线地址

待建仓并开通 GitHub Pages 后填写，骨架阶段无公开地址。

## 本地怎么打开

在仓库目录运行任意静态文件服务器后打开 index.html，例如 python3 -m http.server，然后访问 http://localhost:8000 。
导出状态：已由主代理导出并放入 index.html。

## 数据存在哪里

本工具不在浏览器里长期存数据：队伍配置靠页面内的“导出队伍配置（.json）/ 导入队伍配置”在本地文件里保存，关掉页面即回到初始状态。不会上传到 GitHub 或任何服务器。仓库里只有程序文件，没有任何人的使用数据。

## 已知限制

本仓为部署版，源码结构未整理，不可二次开发。代码是打包产物，他人可以打开使用和自行部署，但无法在此基础上改功能或提交贡献。可维护源码版属于 v2 范围，需按单个空间另行重构。功能与数据的更新节奏不做承诺。
